# Saranja Jeyaradnarajah — Professional Portfolio

A responsive personal portfolio website for Saranja Jeyaradnarajah, an ICT undergraduate at the University of Vavuniya, Faculty of Technological Studies.

## Features
- Responsive desktop, tablet and mobile layout
- Home, About, Education, Skills, Projects, Experience & Activities, CV and Contact sections
- Light/dark theme toggle
- Mobile navigation
- Recruiter-friendly project cards
- LinkedIn, GitHub and email links
- CV download placeholder
- Accessible skip link and reduced-motion support
- Frontend-only contact form ready for a form service/backend

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts (Inter)

## How to Run
Open `index.html` in a browser, or use VS Code Live Server.

## Before Deployment
1. Add the final CV PDF as `cv/Saranja_Jeyaradnarajah_CV.pdf`.
2. Replace project placeholders with real project screenshots, descriptions, contributions and links.
3. Replace `#` Live Demo links with real URLs, or remove them if no demo exists.
4. Connect the contact form to a backend or form service.
5. Add project screenshots inside `images/`.
6. Test all links and content on mobile and desktop.
